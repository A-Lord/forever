# Spacing

Tokens from `ui/styles/theme/spacing.css`. The spacing scale itself is dynamic: any multiple of `0.25` is a step, and one step is 3.5px at this repo's 14px root, so `p-1.25` is exactly 4.375px and `w-4.5` is 15.75px. Convert a px value to its exact step rather than writing `[Npx]`.

## Base scale

The steps a component token should alias. Each square is `--spacing(n)` wide and tall.

<BaseSpacingScale />

## Named lengths

Every `--spacing-*` and `--size-*` token whose value is a plain `px` or `rem` length or a `--spacing(n)` step, drawn as a square of that size.

<SpacingScale prefixes={['spacing', 'size']} />

## Containers

`--container-*` tokens with a plain length, drawn as a bar of that width.

<SpacingScale prefixes={['container']} bar />

## Responsive overrides

`ui/styles/theme/breakpoints.css` re-declares these on `:root` per breakpoint, so `p-page`, `gap-section` and the header offset change with the viewport.

## Runtime variables

`ui/styles/theme/vars.css` declares plain `:root` variables, not `@theme` tokens: no utility is generated for them. A component reads one with the paren shorthand (`w-(--x)`) or from a `ui-*` class.
