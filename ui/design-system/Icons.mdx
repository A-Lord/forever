# Icons

`Icon` from `@ui-kit/Icon` renders FontAwesome 7 as inline SVG, from the definitions `ui/ui-kit/Icon/definitions.ts` imports. Every `IconName` in `ICON_NAMES`, in each style. The regular column is filled only for the glyphs FontAwesome Free ships in regular; `Icon` draws the others solid. The brands column is filled only for the brand icons.
