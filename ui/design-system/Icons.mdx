# Icons

`Icon` from `@ui-kit/Icon` renders FontAwesome 6, loaded from the CDN sheet in the page head. Every `IconName` in `ICON_NAMES`, in each style. A crossed box is a glyph FontAwesome Free does not ship in that style; the brands column is filled only for the brand icons.
